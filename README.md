# Integer to American English Words

Integer to American English Words provides the American-English names for given integers.  
Start date: 2020-10-04  

## Dependencies

- Microsoft Windows
- C++14

## Usage

`IntegerToAmericanEnglishWords <integer1> [anyAdditionalIntegers]`

### CLI

If `<integer1>` is not provided, the program will prompt for and use the inputs of the first line of standard input.
